# FSK BER bench (phase 1)

Simulation, fs = 48000 Hz, 100 random bytes × 20 seeds per point (16000 data bits). SNR is measured over the full band 0–fs/2; Eb/N0 = SNR + 10·log10(fs / 2Rb) with Rb = baud rate. "Decision BER" counts wrong data bits in bytes received at the right time; "total BER" also counts each lost byte as 8 wrong bits.
